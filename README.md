## Running Locally

No build step needed. Just open the file:

```bash
git clone https://github.com/AtulAravindDas/My-Personal-Website.git
cd My-Personal-Website
open index.html
```

Or serve it locally:

```bash
python -m http.server 8000
# → http://localhost:8000
```
